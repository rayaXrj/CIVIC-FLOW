# India administrative location data

These JSON catalogs are derived from India Local Government Directory (LGD) archive data and bundled from the open-source `kalyangupta12/indian-cities-data` project: https://github.com/kalyangupta12/indian-cities-data

The source repository declares the MIT License; its license is included as `LICENSE.data`. The metadata snapshot bundled here was synced on 2026-09-23. The upstream says its source is public LGD archive snapshots curated by `ramSeraph/opendata`. These data aid location selection; they are not a substitute for a live government registry, and city-level coverage represents urban local bodies rather than every informal locality.
